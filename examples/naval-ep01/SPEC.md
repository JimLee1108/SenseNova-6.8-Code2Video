# SPEC: 《纳瓦尔宝典》第 1 集 · 21 句精编版

## 1. 核心定位
- **主题**：破除工时陷阱，打造睡后资产，把自己产品化
- **形式**：9:16 竖屏（1080×1920），3Blue1Brown 暗黑荧光动效风格
- **目标时长**：170 秒（5100 帧 @ 30fps）
- **母带标准**：EBU R128 (-14 LUFS, True Peak <= -1 dBTP)

## 2. 叙事结构（4 幕递进）
- **第一幕（S01–S04）：工时陷阱的天问**
  - 通勤打工人 80 小时无资产 ➔ 停工收入即归零 ➔ 努力与财富没有线性关系 ➔ 金钱是工时欠条，财富是睡后资产。
- **第二幕（S05–S09）：支点一·专长与把自己产品化**
  - 核心公式发布：把自己产品化 ➔ 专长+杠杆+判断力三脚架 ➔ 警惕批量可替代技能 ➔ 苦役 vs 玩耍 ➔ 成为你自己无人能敌。
- **第三幕（S10–S16）：支点二·商业杠杆与免许可飞轮**
  - 双手只能卖一次 ➔ 劳动力杠杆 ➔ 资本杠杆 ➔ 旧杠杆的死门（需许可） ➔ 互联网代码与媒体（0 边际成本） ➔ 服务器机器人 24h 打工 ➔ 放大上千倍成为超级平台。
- **第四幕（S17–S21）：支点三·判断力与终极自由**
  - 杠杆双刃剑（偏离全盘崩塌） ➔ 支点三判断力 ➔ 千亿企业 85% vs 75% 决定百亿价值 ➔ 纳瓦尔 $5000 时薪与深度思考 ➔ 回到早上七点通勤清晨 ➔ 打造无限复制的产品。
