# FACTS: 《深度工作》(Deep Work) 核心事实与概念核查表

1. **作者信息**：
   - 卡尔·纽波特（Cal Newport），乔治城大学计算机科学教授，畅销书作家。
   - 原书名：*Deep Work: Rules for Focused Success in a Distracted World*（2016 年出版）。

2. **核心定义对比**：
   - **深度工作（Deep Work）**：在无干扰的状态下专注进行职业活动，使个人的认知能力达到极限。这种努力能够创造新价值，提升技能，而且难以复制。
   - **浮浅工作（Shallow Work）**：对认知要求不高的事务性任务，往往在受到干扰的情况下开展。此类工作通常不会为世界创造太多新价值，且容易被他人或自动化算法替代（如秒回消息、填表、无效会议）。

3. **三大核心科学机制与公式**：
   - **高质量工作产出公式**：
     $$\text{高质量工作产出} = \text{时间} \times \text{专注度}$$
     *(High-Quality Work Produced = Time Spent × Intensity of Focus)*
   - **注意力残留（Attention Residue）**：
     由明尼苏达大学（后任教于华盛顿大学）教授索菲·勒鲁瓦（Sophie Leroy）在 2009 年研究中提出。当你从任务 A 切换到任务 B 时，你的注意力并没有立刻跟过来，任务 A 的残留思绪会滞留大脑长达 15~25 分钟，导致当前认知表现暴跌。
   - **髓鞘质（Myelin）神经科学**：
     高度专注的练习会刺激大脑神经元轴突周围生长出更厚的髓鞘质（绝缘脂质层），让神经信号传导更快、更精准，这是构建顶级技能回路的生理基础。

4. **深度工作的四大哲学模式（Rhythmic / Bimodal / Monastic / Journalistic）**：
   - **禁欲主义模式（Monastic）**：彻底隔绝一切外部干扰（如唐纳德·克努特）。
   - **双峰模式（Bimodal）**：将时间划分为整块闭关期与开放期（如卡尔·荣格建塔楼闭关）。
   - **节奏模式（Rhythmic）**：最适合普通人的模式——每天固定同一时间段（如清晨 90~120 分钟）建立无干扰专注链条（杰里·宋飞“画叉法”）。
   - **新闻记者模式（Journalistic）**：随时随地切入深度状态（需要极高训练水平）。

5. **行动准则**：
   - 像大公司一样建立深度工作仪式感（固定地点、固定时长、断网规则）。
   - 拥抱无聊（训练大脑耐受无多巴胺刺激的能力，不在排队等电梯时刷手机）。
   - 远离社交媒体与碎片化噪音（二八法则筛选高价值工具）。
   - 彻底抽干浮浅工作（给每天设定明确的停工时间，如 17:30 关机仪式）。
