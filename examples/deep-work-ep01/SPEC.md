## 1. 核心定位
- **原著**：卡尔·纽波特（Cal Newport）《深度工作：如何有效使用每一点脑力》

- **格式**：9:16 竖屏（1080×1920），30 FPS，总时长 168 秒（5040 帧）
- **视觉美学**：3Blue1Brown 暗夜荧光动效风格（黑曜石网格 `#080B10` + 青色激光神经回路 + 霓虹红注意力残留干扰波 + 翡翠绿/鎏金髓鞘质光纤加速）
- **音频标准**：EBU R128 (-14 LUFS, True Peak <= -1 dBTP)，支持本地 Edge-TTS `zh-CN-YunxiNeural` 一键合成
